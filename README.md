# team-arkod

# Название

Сервис аналитики и прогнозирования матчей АПЛ (Английская премьер лига)

## Проблема

Болельщикам и любителям футбольной статистики приходится самостоятельно собирать результаты матчей и сравнивать показатели команд.
Сервис объединит получение данных и их анализ в одном процессе, сохранит результат. Прогноз будет рассчитываться простым статистическим методом по историческим результатам команд. Он отражает оценку вероятностей и не гарантирует исход матча.

## Пользователи

Болельщики-аналитики, спортивные блогеры.

## Границы системы

В первую версию входят:

- получение расписания и исторических результатов матчей АПЛ из внешнего HTTP API
- сравнение статистики двух команд
- расчёт вероятностей исходов выбранного матча
- создание задачи анализа, просмотр её состояния и результата
- хранение задач, их параметров и результатов
- обработка неверных параметров, нехватки данных и сбоев внешнего источника
- отдельный пользовательский веб-интерфейс

В первую версию не входят:

- обучение собственной ML-модели
- поддержка других лиг
